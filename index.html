ArcGIS Layer Finder

Colle l'URL d'une application ArcGIS (Instant Apps, StoryMaps, Dashboards, webmap...), d'une carte Ma Carte IGN (macarte.ign.fr), ou directement un ID d'item ArcGIS : l'outil remonte la config et liste les services (MapServer / FeatureServer / WMS / WMTS / ...) exploitables dans QGIS. Pour toute autre URL, l'outil tente une récupération directe de la page (ça marche si le site autorise le CORS, sinon colle son code source ci-dessous).

Autres geoserveurs (WMS / WFS / WMTS / GeoServer / QGIS Server...)

Pour un site qui n'est pas une app ArcGIS Online : colle le code source (Ctrl+U) ou un bundle JS de la page. Aucune requête réseau n'est faite, juste une extraction d'URLs par motif.
