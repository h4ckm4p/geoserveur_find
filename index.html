ArcGIS Layer Finder

Colle l'URL d'une application ArcGIS (Instant Apps, StoryMaps, Dashboards, webmap...), d'une carte Ma Carte IGN (macarte.ign.fr), ou directement un ID d'item ArcGIS : l'outil remonte la config et liste les services (MapServer / FeatureServer / WMS / WMTS / OGC API / GeoPackage / ...) exploitables dans QGIS. Pour toute autre URL, l'outil tente une récupération directe de la page (ça marche si le site autorise le CORS, sinon colle son code source ci-dessous).

Comment ça marche ? (4 modes, du plus auto au plus manuel)
  1. ArcGIS — URL d'app ArcGIS Online ou ID d'item : 100% automatique.
  2. Ma Carte IGN — URL macarte.ign.fr/carte/... : 100% automatique.
  3. Fetch direct — toute autre URL : tentative automatique, ne marche que si le site autorise le CORS (rare).
  4. Texte brut — colle le code source (Ctrl+U) ou des URLs copiées depuis l'onglet réseau du navigateur : marche toujours, mais c'est à toi de fournir le texte.
